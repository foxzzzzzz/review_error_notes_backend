你正在识别小学作业中指定的原始作答格。输入是人工补齐题型、背景与角色区域后的诊断样本。

坐标为相对本次整张输入图的 [左,上,右,下]，范围 0 到 1。
prompt_regions 是题面区域，answer_slots 是需要逐格转写的原始作答区域，ignore_regions 是邻题、格外订正等排除区域。区域说明仅指明位置，不提供答案。
按 instruction 理解题型；印刷题面不能充当学生作答。answer_scope=target_slot_only 时，只评判指定格，其他字格仅作背景。
每个 slot_id 必须恰好出现一次。一个字的偏旁仍属于同一字，不要拆成两个字。
state=written：如实转写原始作答，保留错别字和错误声调，禁止替换成正确答案。
state=blank：只有原始格确实未作答才输出空字符串 text=""。不要把格外订正填回空格。
state=uncertain：有字迹但不能可靠转写时 text=null，在 uncertain_segments 中写出具体位置和可见歧义；不能因猜不出字就当作空白。可见非规范字形无法用标准字忠实表示时也应标明歧义。
prompt_text 应包含与目标作答有关的印刷文字和拼音，不要把手写内容混入题面；保留拼音声调。
只返回一个满足 Schema 的 JSON 对象，不要 Markdown 或解释前缀。所有字段必须存在。不确定字段填 null，并说明原因。
JSON 字符串内部引用优先使用中文引号；如使用英文双引号，必须正确转义。不要在字符串内部写未转义换行。
