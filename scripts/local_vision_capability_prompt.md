查看这张作业图片。CONTEXT 是整页预览，其中蓝框仅指出待检查区域；TARGET 是该区域的原始清晰图。蓝框不是教师批改。只判断 TARGET 所属局部作答，不替邻题判错。

识别教师红色手写圈、叉或下划线是否对本处作答表示错误，并定位其指向的字词。圈可能不闭合、笔画可能淡或遮挡，不要求圈叉同时出现。规则印刷红框/红线、学生笔画以及只有改写的红字，不自动等于本题错误批改。结合可见笔迹及归属判断，不仅凭字写得是否正确来找错题。

需要时从 CONTEXT 读取题型指令，区分“选正确读音”和“划掉错误读音”。仅给出被批改的局部字词，不恢复整句、整首诗或生成答案解析。word 是该处印刷汉字或拼音所对应的局部字词，marked_text 是其中实际被批改的字；这里不是要求转写学生写错的字。读不清时允许 null，不用正常答案猜补学生原答。若一个圈覆盖同一词的多个字，合为一项；同处圈叉不重复计数。

返回严格JSON，所有字段均必须出现：
{"case_id":"__ID__","verdict":"wrong|not_wrong|uncertain","targets":[{"word":"局部字词或null","marked_text":"被批改字或null"}],"evidence":"简述可见批改及其归属；不推测未见笔迹"}

wrong：能够确认本处存在错误批改，targets 至少一项，文字可为 JSON null。
not_wrong：能够明确排除本处错误批改，targets 必须为空。
uncertain：批改性质或归属不足以确定，targets 必须为空；不能为满足格式强选。
只返回这一个case_id的结果，不输出坐标、候选编号、置信度、学生原答或解释题目的答案。
